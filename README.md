# 📝 Умный конспект

Цифровой сервис для совместной работы с учебными материалами, объединяющий конспектирование, автоматическую генерацию проверочных вопросов с помощью ИИ и аналитику понимания материала для преподавателя.

## 🎯 Проблема

Студенты тратят много времени на конспектирование лекций, поиск ответов в разрозненных записях и подготовку к экзаменам. Преподаватели не видят, какие темы вызывают у студентов наибольшие трудности. Существующие решения (заметки, чаты, LMS) не связаны между собой.

## 💡 Решение

«Умный конспект» — веб-приложение, которое:
- Объединяет конспектирование с проверкой знаний
- Автоматически генерирует вопросы по конспектам с помощью ИИ
- Предоставляет преподавателю аналитику понимания материала
- Создаёт единую экосистему для учебного процесса

## ✨ Основные возможности

### Для студентов
- 📝 **Блочный редактор конспектов** — заголовки, текст, формулы, код, изображения, Markdown
- 🤖 **ИИ-помощник** — генерация вопросов, упрощение текста, суммаризация
- ✅ **Самопроверка** — прохождение тестов с разбором ошибок
- 🔍 **Полнотекстовый поиск** — по своим и общим конспектам
- 💬 **Комментарии** — совместная работа над конспектами
- 🔥 **Серия дней (streak)** — геймификация для мотивации
- 📤 **Экспорт** — в Markdown и PDF
- 🌳 **3D-визуализация** — интерактивные деревья и графы

### Для преподавателей
- 📊 **Аналитика курса** — тепловая карта сложности тем
- 📈 **Статистика студентов** — успеваемость и проблемные зоны
- 📚 **Управление материалами** — официальные конспекты и темы
- 🎯 **Визуализация связей** — граф зависимостей между темами

### Общие функции
- 🌓 **Тёмная тема** — комфортная работа в любое время
- 🎨 **Дизайн-система** — страница с визуализацией токенов DESIGN.md
- 👥 **Две роли** — студент и преподаватель с разными правами
- 📱 **Адаптивный дизайн** — работа на десктопе и мобильных

## 🛠 Технологии

- **Frontend:** React 18, TypeScript, Vite
- **Стилизация:** Tailwind CSS v4, CSS-переменные
- **Маршрутизация:** React Router v6

- **Markdown:** marked
- **Дизайн-система:** DESIGN.md (Google Labs)

## 🎨 Дизайн-система

Проект использует формат DESIGN.md от Google Labs для описания визуальной идентичности. Все дизайн-токены (цвета, типографика, отступы, скругления, тени) определены в файле `DESIGN.md` и интегрированы через CSS-переменные.

Просмотреть дизайн-систему можно в приложении по маршруту `/design`.

### Основные токены
- **Цвета:** Primary (#4F46E5), Secondary (#7C3AED), Accent (#F59E0B)
- **Типографика:** Inter (основной), JetBrains Mono (код)
- **Отступы:** 4px, 8px, 16px, 24px, 32px, 48px, 64px
- **Скругления:** 6px, 8px, 12px, 16px, 20px, 9999px
- **Тени:** sm, md, lg, xl

## 📊 Аналитика

### Тепловая карта сложности
Визуализация тем по уровню ошибок студентов (красный = сложно, зелёный = легко).

### Статистика студентов
- Средний балл по каждому студенту
- Количество пройденных тестов
- Прогресс по темам

### Распределение попыток
Гистограмма активности по темам курса.

### Граф связей
Визуализация зависимостей между темами.

## 🎮 Геймификация

- **Серия дней (streak)** — счётчик непрерывных дней активности
- **Достижения (бейджи)** — первый конспект, первый тест, 5 конспектов, 100% на тесте
- **Визуальное вознаграждение** — анимированные бейджи в профиле
